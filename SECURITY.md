# Security

## Reporting a vulnerability

Please report security problems privately by email to **security@playeaw.com**, not in a public issue.

Include what you found, where (the site, the Windows app, the multiplayer lobby or the updater), and the steps to
reproduce it. We will acknowledge your report, keep you informed while we look into it, and credit you when the fix
is released unless you prefer to stay anonymous. Please give us a reasonable time to fix the problem before you
disclose it publicly.

## Scope

- The site at [playeaw.com](https://playeaw.com) and the code in this repository
- The Windows app and its updater (the releases of this repository)
- The multiplayer lobby (lobby.playeaw.com, `lobby/`)

Only the latest release is supported. Problems in the original game or in third-party mods are out of scope.
