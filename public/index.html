Protected folders

      

        

          Browsers will not let a page keep a folder that lies in one of these. Steam installs the game in the first two by default. Out of
          one the browser remembers the folder; in one it opens in compatibility mode, and you choose it again each time you launch.
        

        
    
          
  • C:\Program Files\
    • 
          
  • C:\Program Files (x86)\
    • 
          
  • C:\Windows\
    • 
          
  • C:\Users\<name>\AppData\
    • 
          
  • 
            C:\Users\<name>\ itself, or a whole drive such as C:\ or D:\ (a folder inside them
            is fine)
          
    • 
        

        
Folders such as D:\SteamLibrary\, C:\Games\ or Documents are fine.

        
    
          
  1. 
            
    Steam
    
            Open Settings → Storage, add a new library folder, for example C:\SteamLibrary or
            D:\SteamLibrary. Then pick the game in the list, click ⋯ and choose Move. Steam keeps working
            with it in the new place.
          
    2. 
          
  2. 
            
    Another copy (Gold Pack, GOG)
    
            Move or copy the Star Wars Empire at War folder to a place such as C:\Games\.
          
    3. 
          
  3. 
            
    Choose it again
    
            Click Choose your game folder… and pick the folder in its new place.
          
    4. 
        

      

      

    

    
      
Making a game archive

      

        

          An archive is your game folder packed into one .tar file, which any browser can import, also on a phone or tablet
          once you copy the file there. Expect about 4 GB.
        

        
    
          
  1. 
            
    Find the game folder
    
            Steam: right-click Star Wars Empire at War: Gold Pack → Manage → Browse local files. It is the folder
            with GameData and corruption in it, usually
            
    
              C:\Program Files (x86)\Steam\steamapps\common\Star Wars Empire at War
            
    
          
    2. 
          
  2. 
            
    Pack it into a .tar
    
            
    
              
            
    
            
    
              
    
                Go up one level so you see the Star Wars Empire at War folder itself, right-click it and choose
                Compress to → TAR File. Windows puts the .tar next to it (if it asks for permission there,
                copy the folder to your Desktop first and compress that).
              
    
            
    
            
    
              
    In the game folder, click the address bar, type cmd and press Enter. In the window that opens, run:
    
              
    
                tar -cf "%USERPROFILE%\Desktop\empire-at-war.tar" GameData corruption
              
    
              
    This works on Windows 11 too. The file lands on your Desktop.
    
            
    
            
    
              
    Open a terminal in the game folder and run:
    
              
    
                tar -cf ~/empire-at-war.tar GameData corruption
              
    
            
    
          
    3. 
          
  3. 
            
    Import it
    
            Drop the .tar on Import an archive. It is copied into this browser's storage once; afterwards you can
            delete the file. A gzipped .tar.gz works too, but not .zip or .7z.
          
    4.
